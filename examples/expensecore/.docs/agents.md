# Protocolo para agentes

1. Consultar el [contexto](README.md), requisitos y decisiones relevantes.
2. Respetar ADR aceptados; proponer cambios mediante ADR o RFC si están habilitados, o solicitar que se habiliten.
3. No inventar evidencia, requisitos ni aprobaciones.
4. Ejecutar las verificaciones disponibles e informar archivos modificados, comandos y resultados.
5. Distinguir lo implementado de lo pendiente.
6. No divulgar secretos ni realizar acciones fuera de los permisos concedidos.
