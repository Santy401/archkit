# ArchKit 0.1.0

Primera base funcional de ArchKit: un asistente CLI reproducible para arquitectura y estándares documentales.

- Cuatro arquitecturas y tres perfiles documentales con plantillas locales.
- Repositorio único, monolito o monolito modular, con decisiones separadas.
- Configuración YAML/JSON schemaVersion 1 y generación sin sobrescrituras.
- ADR/RFC con índices y numeración independiente.
- Validación DOC-001 a DOC-012 en formato humano y JSON.
- Agentes, calidad básica y Git opcionales.
- ExpenseCore generado con el motor real y suite de pruebas sin red.
- Distribución como create-archkit, ejecutable archkit, bajo MIT.

Requisitos: Node >=22.14.0. Los proyectos generados son estructuras y contratos ilustrativos, sin framework ni instalación de dependencias. Monorepos, servicios independientes y plugins externos quedan fuera de esta versión.

## Instalación

```bash
npx create-archkit@0.1.0 init my-project
pnpm dlx create-archkit@0.1.0 init my-project
```

Para instalación local, descargar el tarball adjunto y ejecutar `npm install --global ./create-archkit-0.1.0.tgz`.
